# chinese-quant-agent 产品需求规格 (PRD)

> 基于多智能体 LLM 的中文金融交易框架

## 一、核心功能清单

### 1. 单股研究（Stock Research）
- **多智能体辩论式分析**，支持 **5 级深度**（从快速概览到深度尽调）
- **多情景观点呈现**：牛市/熊市/震荡等不同情景下的观点对比
- 参与角色：基本面分析师、技术面分析师、风控、策略师等，采用辩论（debate）机制收敛结论

### 2. 通用研究（General Research）
- 自然语言提问，研究**任意市场主题**（行业、板块、宏观、个股对比等）
- 不局限于单只股票，支持开放式研究任务

### 3. 股票筛选（Stock Screener）
- **自然语言 + 条件筛选**相结合
- 从 **6000+ 只 A 股**中发现标的
- 支持多维度条件：市值、PE/PB、涨跌幅、行业、技术形态等

### 4. 选股助手（Stock Picker）
- 按**研究需求描述**（自然语言）匹配候选股票池
- 从需求 → 筛选 → 候选标的的智能推荐链路

### 5. 智能助手（Smart Assistant）
- **联网搜索**：实时获取外部信息
- **工具调用（function calling）**：调用数据接口、指标计算等
- **事实记忆**：沉淀并复用已知事实

### 6. AI 记忆（AI Memory）
- **项目级记忆**：跨会话的项目上下文
- **事实沉淀**：从研究过程中抽取并固化关键事实

### 7. Skill 中心（Skill Center）
- **创建和管理自定义数据获取技能**
- 允许用户扩展数据源与获取逻辑

### 8. 模拟交易（Paper Trading）
- **纸面交易**：虚拟买卖、持仓管理
- **复盘**：交易记录回顾、收益统计、策略评估

## 二、技术架构

### 后端（Python）
- 多智能体编排（辩论机制、5 级深度）
- LLM 接入层（OpenAI 兼容，可本地运行）
- 数据层（akshare 等，可扩展 Skill）
- 记忆系统（项目级记忆 + 事实沉淀）
- 工具调用框架（function calling + 联网搜索）
- 模拟交易引擎
- Web API 服务（FastAPI）

### 前端（Vue 3）
- Vue 3 + TypeScript + Vite
- Element Plus + ECharts
- 各功能模块独立视图

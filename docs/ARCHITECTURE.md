# 技术架构设计

## 后端分层

```
┌─────────────────────────────────────────────┐
│              FastAPI Web 服务                 │
│         (REST API + SSE 流式输出)             │
├─────────────────────────────────────────────┤
│              编排层 (Orchestrator)            │
│  单股研究│通用研究│筛选│选股│助手│模拟交易      │
├─────────────────────────────────────────────┤
│        多智能体层 (Agents)                    │
│  分析师│技术面│风控│策略师│辩论主持人│研究员     │
├─────────────────────────────────────────────┤
│        能力层 (Capabilities)                  │
│  工具调用│联网搜索│技术指标│记忆│Skill 注册     │
├─────────────────────────────────────────────┤
│            LLM 接入层 (OpenAI 兼容)           │
│   DeepSeek│Qwen│vLLM│Ollama│LM Studio ...     │
├─────────────────────────────────────────────┤
│            数据层 (Data Providers)            │
│   akshare│自定义 Skill│缓存                    │
└─────────────────────────────────────────────┘
```

## 关键设计

### 1. 辩论式分析（5 级深度）
- 多 Agent 独立分析 → 辩论主持人引导观点碰撞 → 多轮收敛
- 深度等级控制：Agent 数量、轮次、数据详略、输出长度

### 2. 多情景观点
- 每个 Agent 输出在牛/熊/震荡情景下的差异化观点
- 策略师整合为情景矩阵

### 3. 工具调用与联网
- function calling 协议接入数据接口
- 可选联网搜索模块（可配置搜索引擎/API）

### 4. 记忆系统
- 项目级：SQLite / 向量库存储项目上下文
- 事实：从研究结论抽取结构化事实，可复用

### 5. Skill 中心
- 插件化数据获取技能注册
- 用户可创建自定义 Skill（声明式配置或脚本）

### 6. 模拟交易
- 内存/持久化的持仓与订单账本
- 基于历史与实时行情的虚拟撮合
- 收益统计与复盘报告

### 8. 记忆系统
- `memory/store.py`：JSON 持久化存储（事实 + 会话 + 对话历史）
- `memory/extractor.py`：LLM 事实抽取器（失败降级启发式）
- 事实记忆跨会话复用，供智能助手工具调用

### 9. 工具调用框架
- `tools/base.py`：Tool 抽象 + OpenAI function calling 协议
- `tools/registry.py`：工具注册与执行
- `tools/builtin.py`：内置工具（行情/指标/搜索/记忆）

### 10. 智能助手
- `assistant/agent.py`：工具调用循环（最多 5 轮）
- `assistant/search.py`：联网搜索（DuckDuckGo）

### 11. 通用研究 / 筛选 / 选股
- `research/general.py`：开放主题流式研究
- `screener/screener.py`：条件 + 自然语言筛选
- `picker/picker.py`：需求 → 筛选 → LLM 推荐

### 12. Skill 中心
- `skills/manager.py`：技能注册与管理
- `skills/builtin.py`：内置技能示例

### 13. 模拟交易
- `trading/models.py`：订单/持仓模型
- `trading/account.py`：纸面账户（现金/持仓/盈亏）
- `trading/engine.py`：对接数据源的下单引擎
